◆ TransmitirAudio()

error TransmitirAudio ( pb::AudioRequest *  peticion,
string  direccionCliente,
pb::AudioService_AudioStreamServer  stream 
)

Transmite un archivo de audio al cliente fragmento a fragmento.

Antes de iniciar el envío publica, de forma asíncrona, la información de la reproducción en la cola de mensajes. Si el cliente abandona la reproducción el envío se detiene.

Parámetros
peticionPetición gRPC con el archivo y los datos del audio.
direccionClienteDirección IP:puerto del cliente.
streamFlujo gRPC por el que se envían los fragmentos.
Devuelve
nil si el audio se envió completo, o un error gRPC (NotFound, Canceled, Internal).
